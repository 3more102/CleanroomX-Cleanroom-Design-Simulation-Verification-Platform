CLEANROOMX RELEASE VALIDATION
=============================

Validation date: 2026-09-25

IMMUTABLE BASELINE

37a83dcce3489397647f27faf41a7c79680aa576

v0.102.1 is a patch release and does not move or rewrite v0.102.0.

V0.102.1 FINAL SPATIAL CLOSURE
- one canonical spatial_layout model remains shared by 2D and 3D
- persisted engineering synchronization provenance and all-or-nothing mapping preflight remain enabled
- pressure relationships derive only from explicit active-analysis pressure_cascade records
- observed relationship delta is computed only when both linked spatial rooms provide pressure
- relationship state is pass/fail/available/unavailable and is rendered in both 2D and 3D
- source and packaged demos open on the verification analysis
- installed GUI smoke requires at least three demo rooms, rendered 2D room geometry, rendered 3D room geometry, and rendered pressure relationships in both views
- no solver equation, numerical tolerance, root-selection rule, uncertainty semantic, project schema version, unit convention, or engineering acceptance criterion is intentionally changed

REQUIRED RELEASE GATE
The normal CI workflow must succeed on the exact commit that is still current main.
That CI runs:
- Python 3.11 / 3.12 / 3.13 complete suites
- v0.91 through v0.95 compatibility regressions
- application/desktop/input-contract/strict-ingestion/project-batch regressions
- Release 2 consolidation regressions
- clean wheel build/install and installed command checks
- Windows PowerShell/CMD checkout launcher smoke
- Python 3.13 performance evidence
- installed Tk/Xvfb cleanroomx-gui --demo --smoke
- representative CLI JSON/Markdown smoke checks

PUBLICATION SAFETY
The v0.102.1 publisher is triggered only by successful CI on main and verifies that the
successful CI commit is still the current main commit before creating the tag/release.
A stale successful CI result is not eligible for publication.

RELEASE BOUNDARY
CleanroomX provides engineering screening, simulation, verification, spatial design, and
software/provenance evidence. It does not by itself establish cleanroom certification, CFD
validation, commissioning/TAB acceptance, manufacturer approval, or regulatory compliance.
